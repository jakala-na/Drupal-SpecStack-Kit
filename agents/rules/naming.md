# Naming rules

- Short tokens (CSS classes, `--*` design tokens, SVG symbol ids): prefix `ssk-` / `--ssk-`.
- Long machine names (modules, themes, packages, Twig namespaces, libraries, `data-*`, Drush): `specstack` / `specstack_*` / `@specstack/*`.
- Non-React JS attachment hooks: `js-*` only (never style them) — `docs/js-classes.md`.
- Do not invent alternate short prefixes beyond `ssk` / `js-`.
- Full table: `docs/naming.md`.
